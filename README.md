# Haeyun Park’s Web Portfolio

This static site requires no build step. Open `index.html` in a browser to see the home page. Edit `experience.html` for education and activities, and `portfolio.html` for projects.

To publish with GitHub Pages, put these files and the `assets` folder in the root of the `levicorp-us.github.io` repository. Select the root of the `main` branch under **Settings → Pages**. [GitHub Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)
